# ManaVoice AI — Model Training & Fine-Tuning Guide

This guide details the machine learning training architecture, fine-tuning protocols, dataset workflows, and execution procedures implemented in ManaVoice AI.

---

## 1. Architectural Strategy: Parameter-Efficient Fine-Tuning (PEFT / LoRA)

Training foundation models from scratch requires cluster-scale compute. ManaVoice AI implements **Low-Rank Adaptation (LoRA)** on sequence-to-sequence transformer attention projections ($W_q, W_v$).

### Advantages of Platform LoRA Integration:
- **Low Compute Overhead**: Reduces trainable parameters by over 98%, enabling training on workstations with 6GB–16GB VRAM or multi-core modern CPUs.
- **Modular Adapter Checkpoints**: LoRA weight diffs are lightweight (~15MB–50MB), allowing rapid switching of language adapters without reloading multi-gigabyte foundation weights.
- **Zero Catastrophic Forgetting**: Preserves foundational multi-lingual representations while specializing in Indian regional accents and domain vocabularies.

## 2. Training Profiles

The training pipeline supports four standardized profiles configured in `app/services/training_service.py`:

| Profile | Epochs | Batch Size | Learning Rate | Max Samples | Target Environment |
|---|---|---|---|---|---|
| `smoke_test` | 1 | 2 | $1 \times 10^{-4}$ | 10 | CI / Verification |
| `small` | 3 | 4 | $5 \times 10^{-5}$ | 200 | Local Workstation CPU/GPU |
| `medium` | 10 | 8 | $3 \times 10^{-5}$ | 2,000 | Dedicated GPU (RTX 3050/4060) |
| `full` | 25 | 16 | $1 \times 10^{-5}$ | 50,000+ | Cloud Compute / High VRAM |

## 3. Data Pipeline & Manifest Specification

All training runs ingest versioned JSONL manifests generated by the dataset discovery and preprocessing service.

### Manifest Format (`manifest.jsonl`):
```json
{"audio_filepath": "D:/ManaVoice_Data/datasets/fleurs/train/001.wav", "duration": 4.25, "text": "నమస్కారం, మీరు ఎలా ఉన్నారు?", "language": "te", "speaker_id": "spk_01"}
{"audio_filepath": "D:/ManaVoice_Data/datasets/fleurs/train/002.wav", "duration": 3.80, "text": "ఈ రోజు వాతావరణం చాలా బాగుంది.", "language": "te", "speaker_id": "spk_02"}
```

### Preprocessing Checklist:
1. Audio resampled to 16,000 Hz, 16-bit Mono PCM.
2. Silence trimmed using FFmpeg `silenceremove` filter.
3. Transcripts normalized with NFKC Unicode normalization.
4. Speaker-isolated train/val/test splits (80% / 10% / 10%) preventing acoustic leakage.

## 4. Triggering Training Runs

### Option A: REST API Execution
Authorized administrators can launch background training jobs via HTTP:

```bash
curl -X POST "http://localhost:8000/api/training/jobs" \
  -H "Authorization: Bearer <ADMIN_JWT_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "task_type": "asr",
    "model_id": "openai/whisper-large-v3-turbo",
    "dataset_name": "google/fleurs-te",
    "profile": "smoke_test",
    "target_language": "te"
  }'
```

### Option B: Python Programmatic / CLI Execution
Run a fine-tuning job directly in the terminal:

```powershell
# Set BLAS thread limit to prevent memory overcommit on Windows
$env:OPENBLAS_NUM_THREADS="1"

py -3 -c "
import asyncio
from app.services.training_service import training_service

async def run():
    job = await training_service.start_training_job(
        task_type='asr',
        model_id='whisper-turbo',
        dataset_name='google/fleurs-te',
        profile='smoke_test',
        target_language='te'
    )
    print(f'Training completed: {job}')

asyncio.run(run())
"
```

## 5. Checkpoints & Model Registry

Completed checkpoints are stored in the persistent storage root (`D:/ManaVoice_Data/models/<job_id>/`):

```text
D:/ManaVoice_Data/models/lora_train_660e12/
├── adapter_model.bin         # Trained LoRA delta matrices
├── adapter_config.json       # Hyperparameters (r=8, lora_alpha=16)
├── training_metrics.json     # Per-epoch loss, val_loss, and learning rate
└── evaluation_summary.json   # Post-training WER/CER/BLEU benchmark scores
```

The system automatically registers verified checkpoints into the application model registry, making them immediately selectable in the **Video Studio** and **Export Center**.
